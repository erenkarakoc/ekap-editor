# Supabase şema kaynağı

Bu klasördeki migration dosyaları tarihsel bir kopyadır ve yeni migration kabul etmez.

Tek şema kaynağı üst çalışma alanındaki [`kamu-poz/supabase/migrations`](../../supabase/migrations) klasörüdür. Yönetim merkezi migration'ı da yalnız oraya eklenmiştir. Yerel geliştirme, CI ve üretim şema işlemleri üst çalışma alanından çalıştırılmalıdır.

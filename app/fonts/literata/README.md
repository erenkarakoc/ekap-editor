# Literata display font

Source: https://github.com/google/fonts/tree/main/ofl/literata
Upstream: https://github.com/googlefonts/literata
License: SIL Open Font License 1.1, included in OFL.txt.

The original variable italic font is bundled locally and used at weight 700.
Next.js packages it into static assets for web and the desktop standalone server.
`display-heading` is explicitly applied to page and prominent section headings.
